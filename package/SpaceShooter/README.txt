SPACE SHOOTER — a 60-second polygon space shooter for OnionOS
=============================================================
(Miyoo Mini / Mini Plus)
Built by Claude, Anthropic's AI model, for snyderman3000.
Source, updates and bug reports: https://github.com/snyderman3000/miyoo-SpaceShooter

THE MISSION
  You have 60 seconds. Shoot the cyan drones (+100) and the gold cubes
  (+300). Quick hits in a row build a chain multiplier, up to x4.
  Asteroids, pylons and beams can't be destroyed: touch one and your
  ship explodes. Survive the full minute for a +1000 bonus.

CONTROLS
  D-pad ............ fly
  A or B (hold) .... fire
  L / R (hold) ..... knife-edge bank: sharper, faster sideways dodge
  START ............ pause        SELECT ... music on/off
  MENU ............. pause / exit

INSTALL
  Copy the "App" folder from this zip to the root of your SD card
  (merge it with the App folder that's already there), or install it
  from Mixtape. You'll find it under Apps.

SETTINGS  (App/SpaceShooter/data/config.json)
  music      true/false (SELECT toggles it in the game too)
  invert_y   true for flight-stick controls (up dives)
  page_flip  false if the picture ever looks wrong (turns off tear-free
             double buffering)

FILES
